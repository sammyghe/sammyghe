## How I work

- **Business first.** I start from how good companies solve a problem, then apply it to mine.
- **Systems that run themselves.** I'd rather build the agent that does the job than do the job every week.
- **Real over demo.** Fewer features that truly work beat many that only look good.
- **Check what exists first.** Before building, find the open-source project that already does it.
- **Think out loud, decide clearly.** Most of what I say is a dump. The decisions are short.
